# Module skills

A module that provides core utilities for defining skill metadata, discovering skill content, and composing prompts.


Kroog retains the upstream skill descriptor, discovery and XML, YAML and JSON prompt APIs. JVM discovery uses strict parsing and secure no-follow filesystem sessions, with a bounded immutable adapter for memory-backed providers. Legacy registries provide metadata-only catalogues and a typed `load_skill` tool over captured instructions.

The current source prepares `1.3.0-beta-kroog.2`. Install the confirmed published standalone beta module as `com.kreoh.kroog:skills-jvm:1.1.1-beta-kroog.15`; preparation does not imply publication. See the module README for policies and compatibility details.
